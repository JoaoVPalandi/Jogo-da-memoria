# 🃏 Jogo da Memória

Um jogo da memória desenvolvido com **HTML, CSS e JavaScript**. O objetivo é encontrar todos os pares de cartas com o menor número de tentativas possível.

---

## 🎮 Como jogar

1. Clique em **Iniciar Jogo**.
2. O tabuleiro será montado com as cartas viradas para baixo.
3. Clique em duas cartas para virá-las.

   * Se forem iguais, permanecem viradas.
   * Se forem diferentes, elas voltam a ficar viradas para baixo.
4. Continue até encontrar todos os pares.
5. Ao final, o jogo mostra a mensagem de vitória e permite reiniciar.

---

## ⚙️ Recursos funcionais

* Tela inicial para começar o jogo.
* Tabuleiro com cartas embaralhadas.
* Virar cartas ao clicar.
* Comparação automática entre pares.
* Contagem de tentativas.
* Mensagem de vitória ao finalizar.
* Opção de reiniciar o jogo.

---

## 📌 Recursos não funcionais

* Execução rápida e sem travar.
* Interface simples e intuitiva.
* Layout responsivo (funciona em PC e celular).
* Compatível com navegadores modernos.
